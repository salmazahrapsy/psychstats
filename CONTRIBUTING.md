# Contributing to PsychStats

Thank you for contributing.

## Guidelines

1. Keep articles clear, neutral, and evidence-informed.
2. Prefer authoritative academic, clinical, or institutional sources.
3. Distinguish established findings from hypotheses, interpretations, and opinions.
4. Use descriptive headings and consistent terminology.
5. Add references for substantive factual claims.
6. Avoid presenting educational content as individualized medical or psychological advice.

## Article Workflow

1. Create or update a Markdown file in the appropriate directory.
2. Follow the relevant template in `templates/`.
3. Check headings, links, references, and terminology.
4. Submit the change for review.
